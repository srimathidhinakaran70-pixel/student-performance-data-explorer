Student Performance Data Explorer

A practical demonstration of collecting structured records, maintaining data quality, exploring patterns, and exporting data for further analysis.

⌘

Technologies used

HTML5CSS3JavaScriptChart.jslocalStorageCSV

Built with static frontend technologies and browser-based storage.

▤

Dataset description

The sample dataset contains fictional student records across multiple departments and study years, including attendance and marks.

All sample identities and scores are fictional and intended for demonstration only.

⇄

Database readiness

Records are saved in this browser using localStorage. The storage layer is separated in the JavaScript so it can later be replaced by Supabase or Firebase.

This version does not connect to a remote database.

Ready to explore your data?

Start by loading the sample dataset or collecting your first record.

Run locally

  1. Download or clone the project repository.
  2. Keep index.html, style.css, script.js, and sample-data.csv in the same folder.
  3. Open index.html in a modern browser, or use VS Code Live Server.
  4. Use “Load Sample Data” to populate the dashboard.

Publish with GitHub Pages

  1. Push the project files to a GitHub repository.
  2. Open repository Settings → Pages.
  3. Choose the main branch and root folder, then save.
  4. Wait for GitHub Pages to publish your static site.

Chart.js is loaded from a CDN, so an internet connection is required for charts. Browser localStorage is local to the browser/device and is not shared with other users.
